LVGL 与 ArkUI lite 组件对比演示

左侧 LVGL 复刻 · 右侧 ArkUI lite（small UI_Lite）真实能力 · 缺失能力直接标注

说明

  • 每页为左右双栏：左列 LVGL 复刻演示 + 独立操作区（尽量演示右列缺失的能力），右列 ArkUI lite（small UI_Lite）演示 + 独立操作区；差异对照位于双栏之后、实时生成代码之前。
  • 右列舞台右上角以红色标注「ArkUI lite 无法表达」的能力缺口；左列舞台左上角以灰色标注「LVGL 不可演示」项。
  • 每页底部为双列实时生成代码：左列 LVGL C 代码、右列 ArkUI lite C++ 代码，随操作参数实时刷新；右列渲染参数取自 ui_lite / graphic_utils_lite 源码并附依据说明。
  • 卡片右上角标注 ArkUI lite 的对应情况：能力对齐 / 部分缺失 / 无对应组件；卡片下方列出具体缺口与 ✓/△/✗ 逐项判定计数。
  • 组件按《LVGL_VS_UILITE需求_已刷新》「组件」表的分类列排布（基础与文本 / 进度与数值 / 选择与开关 / 文本输入 / 导航&容器 / 数据展示 / 扩展控件）；卡片上的优先级徽标取自该表「使用频率」列及「组件优先级」表的排名与估算使用率（# 号越小优先级越高）。
  • 优先级徽标后的绿色「项目」标注表示需求表「美的使用」列为"是"（美的项目在用）；紫色「ToB」标注表示需求表「策略」列为 ToB 标准。
  • 左列演示画布统一为 360×220，与官方 examples/widgets 的小屏目标一致；多数页面保留 PNG / GIF / WebM 导出。
  • 覆盖 38 个控件（含新增的「Animation 动效」能力页）、2 种布局（Flex / Grid）与 2 组样式（基础 / 状态过渡）。
