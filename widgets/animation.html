Animation：lv_anim vs ArkUI lite 动效能力

左列为 LVGL 动画引擎复刻演示（缓动曲线 / 时间轴 / 反向往复 / 缩放倾斜 / 状态过渡 / 路径动画 / 可中断）， 右列按 ArkUI lite 最新源码复刻。最新代码新增了多段关键帧、scale、路径动画、元素过渡与页面转场， 但全部是编译期开关且默认关闭，所以右侧提供「默认基线 / 增强能力开启」两档对照。

ArkUI lite 能力档位
实际构建默认关闭；切到增强后可用：多段关键帧、scale、offset-path、显式元素过渡、页面/共享元素转场。
LVGLlv_anim 通用动画引擎 · 任意属性/变量

一个 lv_anim_t 驱动一个属性：逐帧回调写值 + 缓动函数映射进度。时间轴可串行/并行编排，反向往复与暂停都是一行接口，状态过渡可在样式里声明，手势类动画还能随时删掉重起。

LVGL 操作（独立）· 参数对应 LVGL 接口

红点 = 即使增强开启，ArkUI lite 仍无此能力
无限循环
ArkUI liteCSS animation / transition 增强开启 · 多段 / scale / 路径 / 转场

当前为增强能力开启档：@keyframes 可按 0%~100% 多段解析（最多 8 段、每段 5 个并行属性），关键帧支持 scale；另有独立的 offset-path 路径动画与显式 startTransition() 元素过渡。缓动仍只有 4 种，仍无反向、暂停、完成回调、skew/轴心与状态自动补间。

ArkUI lite 操作（独立）· 参数对应 CSS animation / transition

渲染依据：component.cpp（属性白名单 / 缓动 / fill-mode）、app_style.cpp（多段关键帧解析，受增强开关控制）、 keyframes_transition_impl.cpp（≤8 段 / 5 属性并行）、transition_impl.cpp（offset-path 路径动画）、 element_transition.cpp（显式 startTransition）、page_transition.cpp（router.replace 页面转场）。 默认构建全部关闭；右列代码随参数与档位实时生成。
