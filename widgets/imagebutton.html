ImageButton：lv_imagebutton vs UIButton + SetImageSrc

左列为 LVGL 复刻演示（六态图源：默认 / 按下 / 勾选 / 勾选+按下 / 禁用 / 勾选+禁用 全部可配），右列为按 ArkUI lite（OpenHarmony small UI_Lite） 源码渲染的 UIButton + SetImageSrc（仅默认 / 按下两态图）。左右各自独立操作，页面最下方为差异对照。

LVGLlv_imagebutton 六态图源 · 可勾选

六态图源：RELEASED / PRESSED / CHECKED_RELEASED / CHECKED_PRESSED / DISABLED / CHECKED_DISABLED，可用上方预览逐一看图；按住画布显示 pressed（勾选时显示 checked+pressed），松开后若可勾选则在 released / checked 间切换，禁用时完全不响应。

LVGL 操作（独立）· 参数对应 LVGL 接口

点击切换 checked
禁用（显示禁用图）
ArkUI liteUIButton + SetImageSrc 仅两态图 · 自带缩放

SetImageSrc 只能配默认图与按下图两张；图片按资源原尺寸绘制、不缩放也不居中（从内容区左上角开始），右列默认让图片尺寸等于按钮尺寸以贴近真实观感；改宽高会留白或裁切。按住可体验内置 0.8 缩放 + 白色蒙层。

ArkUI lite 操作（独立）· 参数对应 UI_Lite 接口

渲染依据：foundation/arkui/ui_lite/frameworks/components 与 graphic_utils_lite/frameworks/style.cpp 中的源码常量—— 颜色、圆角、线宽、动画时长与贝塞尔控制点均按默认值绘制； 上方参数面板每一项都对应真实 C++ 接口，右列代码随参数实时生成。
