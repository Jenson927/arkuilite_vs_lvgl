Object：lv_obj vs UIView

左列为 LVGL 复刻演示（基类对象 + 百分比定位 / 尺寸 + flex 布局演示），右列为按 ArkUI lite（OpenHarmony small UI_Lite） 源码渲染的 UIView（基础容器）。左右各自独立操作，页面最下方为差异对照。

LVGLlv_obj 百分比定位 · flex 布局

百分比定位：X/Y 按父容器百分比放置；flex 布局：三个子对象按 row / column / wrap 自动排版。

LVGL 操作（独立）· 参数对应 LVGL 接口

ArkUI liteUIView 基础容器 · 对齐度高

UIView 是所有控件的基类：SetPosition / SetSize / Add 与 lv_obj 基本对齐；差异集中在 Style 固定字段与布局宏。

ArkUI lite 操作（独立）· 参数对应 UI_Lite 接口

渲染依据：foundation/arkui/ui_lite/frameworks/components 与 graphic_utils_lite/frameworks/style.cpp 中的源码常量—— 颜色、圆角、线宽、动画时长与贝塞尔控制点均按默认值绘制； 上方参数面板每一项都对应真实 C++ 接口，右列代码随参数实时生成。
