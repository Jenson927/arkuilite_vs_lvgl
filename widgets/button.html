Button：lv_button vs UIButton

左列为 LVGL 复刻演示，右列为按 ArkUI lite（OpenHarmony small UI_Lite） 源码 ui_button.cpp 色值与动画参数忠实渲染的 UIButton。左右各自独立操作，页面最下方为差异对照。

LVGLlv_button 状态可叠加 · 按钮即容器

点击画布上的按钮切换勾选；按下 / 勾选 / 焦点 / 禁用可任意叠加，文字对齐可实时切换。

LVGL 操作（独立）· 参数对应 LVGL 接口

按下 PRESSED
勾选 CHECKED
焦点 FOCUSED
禁用 DISABLED
开启投影
自动循环三种状态
ArkUI liteUIButton 3 状态互斥 · 不画文字

按住画布上的按钮可体验真实按下动效（缩放 0.8 + 白色蒙层）；无阴影——Style 没有阴影字段。

ArkUI lite 操作（独立）· 参数对应 UI_Lite 接口

开启动画与蒙层
挂 UILabel 子控件显示文字
渲染依据：ui_button.cpp / style.cpp —— RELEASED #007dff · PRESSED #1996ff · INACTIVE #617e9d； 按下缩放 SHRINK_SCALE 0.8（150ms 收缩 / 200ms 恢复，Bezier 控制点 0.2）， 白色蒙层 MASK_OPA 25/255；文字默认白色（Style::textColor_ = Color::White()）。
