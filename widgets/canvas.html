Canvas：lv_canvas vs UICanvas

左列为 LVGL 复刻演示（280×180 像素缓冲自由绘制 + 第二图层混合叠加），右列为按 ArkUI lite（OpenHarmony small UI_Lite） 源码 ui_canvas.cpp 图元（线 / 贝塞尔 / 矩形 / 圆 / 扇 / 弧 / 路径 / 描边文字）渲染的 UICanvas。左右各自独立操作，页面最下方为差异对照。

LVGLlv_canvas 像素缓冲 · 图层混合

在白色画布内按住拖动即可绘制；开启第二图层后预置图形画入独立缓冲并半透明叠加，混合模式可切换，贝塞尔曲线为实时叠加路径；右下角圆角矩形为 LVGL 独有的渐变填充（bg_grad），可切线性 / 径向。

LVGL 操作（独立）· 参数对应 LVGL 接口

启用第二图层（独立缓冲 · 半透明叠加 · 预置图形画入该层）
叠加贝塞尔路径
自由绘制始终作用于第一图层；开启第二图层后预置图形（矩形 / 圆 / 对角线 / 文字）画入第二图层并按混合模式合成。撤销最多保留 30 步快照。
ArkUI liteUICanvas 图元齐全 · 无图层/裁剪栈

UICanvas 图元齐全（线 / 贝塞尔 / 矩形 / 圆 / 扇 / 弧 / 图片 / 路径 / 描边文字）；没有图层、混合模式与裁剪栈，贝塞尔线宽上限 3。

ArkUI lite 操作（独立）· 参数对应 UI_Lite 接口

渲染依据：foundation/arkui/ui_lite/frameworks/components 与 graphic_utils_lite/frameworks/style.cpp 中的源码常量—— 颜色、圆角、线宽、动画时长与贝塞尔控制点均按默认值绘制； 上方参数面板每一项都对应真实 C++ 接口，右列代码随参数实时生成。
