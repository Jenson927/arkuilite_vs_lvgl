Checkbox：lv_checkbox vs UICheckBox

左列为 LVGL 复刻演示，右列为按 ArkUI lite（OpenHarmony small UI_Lite） 源码 ui_check_box.cpp 两态与切换动画渲染的 UICheckBox。左右各自独立操作，页面最下方为差异对照。

LVGLlv_checkbox 状态可叠加 · 支持半选

点击画布第一行切换勾选；勾选 / 禁用可叠加，半选（indeterminate）与「勾选+禁用」同时生效是 ArkUI lite 表达不了的。

LVGL 操作（独立）· 参数对应 LVGL 接口

勾选 CHECKED
禁用 DISABLED
显示半选横线
勾选 / 取消循环
ArkUI liteUICheckBox 两态互斥 · 内置切换动画

点击画布上的勾选框可切换；只有 SELECTED / UNSELECTED 两态，没有半选，也没有禁用叠加。

ArkUI lite 操作（独立）· 参数对应 UI_Lite 接口

渲染依据：ui_check_box.cpp / ui_abstract_button.cpp —— 两态 SELECTED / UNSELECTED，内置切换动画（DEFAULT_ANIMATION_TIME）； 选中色 SetSelectedStateColor()（主题默认 #007dff）； 文字需另挂 UILabel，无半选状态。
